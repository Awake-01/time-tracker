# Link: https://awake-01.github.io/time-tracker

一款简单的时间记录与统计工具，帮助你记录生活中的某些时刻，并提供数据统计和管理功能。

### 功能特点
1. **时间记录**：一键记录当前时间，并可添加备注信息。
2. **数据统计**：按年/月/周/日不同维度查看时间记录分布情况。
3. **数据管理**：支持记录的查看、编辑、删除，以及数据的导入/导出。
4. **备份提醒**：定期提醒备份数据，防止数据丢失。

### 使用说明
1. 在"记录"标签页点击"记录此刻"按钮，可快速记录当前时间，可选填备注。
2. 在"统计"标签页查看记录的分布情况，可切换不同时间维度。
3. 在"数据管理"标签页管理所有记录，支持导入/导出JSON格式数据。
> 数据存储在本地浏览器，确保隐私安全。
